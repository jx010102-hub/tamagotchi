# 성장 다마고치

나와 함께 성장하는 다마고치 웹앱. 마을 배경 위의 친구들(일본어·인스타툰·릴스·드럼)을 눌러 오늘 공부·작업 시간을 확인하고, 타이머나 직접 입력으로 기록합니다.

- 주소: https://jx010102-hub.github.io/tamagotchi/
- 아이패드: Safari에서 열고 공유 → 홈 화면에 추가
- 기록은 기기 안에 저장됩니다. 설정 탭의 "백업 저장"으로 가끔 백업해 주세요.

## 💬 친구들 말풍선
- 앱을 열면 모찌·릴리·콩이·둥둥이가 오늘 일정, 목표, 기록을 보고 자기 말투로 말을 걸어요. 한 번에 최대 2명이 말해요.
- 상황마다 하는 말이 달라요:
  - 처음 열었을 때 인사와 오늘 일정
  - 일정 시작 30분 전
  - 기록 직후 반응
  - 못 한 일정 놀리기
  - 모든 목표를 달성했을 때 단체 대화
  - 일정이 없는 날
- 가끔 친구들끼리 티격태격해요. 하루 한 번까지만 나오고, 일정이 가까우면 나오지 않아요.
- 대사는 `index.html`의 `TALK_LINES`(성격별 준비된 대사)와 `PERSONA`(성격·말투)에 있어요.
- 일정 이름으로 담당 친구를 짐작해요. 예를 들어 '찬양 합주'면 둥둥이가 말해요. 하지만 짐작만으로 스킬 기록에 넣지는 않아요. 완료 체크할 때 직접 고른 것만 기록돼요.

### AI 대사 연결 (선택)
- `server/talk-worker.js`를 Cloudflare Workers에 배포하고, API 키는 `wrangler secret`으로 서버에만 넣어요. 자세한 방법은 파일 위쪽 주석에 있어요.
- 나온 주소를 앱의 **설정 → 마을 배경 → AI 대사 서버**에 넣으면 같은 상황 정보로 새 대사를 받아와요.
- 서버가 없거나 응답이 늦어도(3.5초 넘게 걸리면) 준비된 대사로 그대로 동작해요.
- 원래 대사에 없는 숫자가 들어간 AI 대사는 버려요. 기록·일정이 왜곡되는 걸 막기 위해서예요.

## 🥁 둥둥이의 찬양 콘티 찾기
- 카톡 콘티를 그대로 붙여넣으면 곡 제목을 골라내요. 번호, 키(G, A→B), 이모지, 카톡 이름·시간은 알아서 빼요.
- 그다음 예수사랑교회 채널의 **[성금요일 총체적 치유 찬양기도회]** 영상들에서 그 곡이 나오는 **챕터 시작 지점 링크**를 찾아줘요.
- 같은 곡이 여러 영상에 있으면 가장 최근 영상으로 골라요. 다른 영상은 곡마다 목록에서 바꿀 수 있어요.
- "📋 링크 전체 복사"를 누르면 카톡에 바로 붙여넣을 수 있는 글로 복사돼요.
- 여는 곳: 둥둥이를 누르면 옆 창에 바로 열려요, 드럼 카드의 **🎵 콘티**, 월요일 낮~수요일에 둥둥이 말풍선.
- 영상·챕터 목록(`worship/songs.json`)은 GitHub Actions(`.github/workflows/worship-index.yml`)가 매일 아침 6시와 월요일 낮 12시에 새로 모아요. API 키는 필요 없어요.
  - 바로 새로 모으고 싶으면 GitHub 저장소의 Actions 탭 → "찬양 영상 챕터 모으기" → Run workflow를 누르면 돼요.

### 🥁 메트로놈 · 곡 템포
- 콘티 곡마다 🥁 버튼을 누르면 메트로놈이 열려요.
  - BPM은 40~240까지 맞출 수 있어요. 박자는 4/4·3/4·6/8, 박 나누기는 ♩·8분·16분 중에 골라요.
  - 첫 박에는 강세가 들어가고, 박마다 둥둥이가 통통 튀어요.
- 템포 찾는 방법은 세 가지예요.
  - 📺 **여기서 영상 틀기**: 그 곡 챕터부터 영상을 틀어서 메트로놈과 같이 들을 수 있어요.
  - 🎧 **들려줘서 찾기**: 곡을 12초 듣고 템포를 찾아요. 반이나 두 배로 잡혔으면 버튼 하나로 바꿀 수 있어요.
  - 👆 **탭**: 박자에 맞춰 톡톡 두드려서 맞춰요.
- 💾 저장하면 같은 곡이 다음 콘티에 또 나올 때 그 템포가 자동으로 들어가요.
- 유튜브가 GitHub 서버를 로봇으로 보고 소리를 막아서, 서버에서 미리 템포를 재 두는 방식은 쓸 수 없어요.

## 📌 달력 개인 일정
- 달력의 "＋ 일정 추가"를 누르거나 날짜를 눌러서 약속·생일·병원 같은 일정을 넣어요.
- 넣을 수 있는 것: 이모지, 시간, 여러 날, 반복(매주·매달·매년), 메모.
- 시간표와는 따로 저장돼요. 오늘 일정은 홈 안내 말풍선에도 나와요.

## 🥚 꿈의 방
- 기르고 싶은 스킬을 알로 만들어요. 정할 것: 스킬, 이름, 소품, 색, 목표(하루 몇 분 또는 주 몇 회), 캐릭터 그림(선택).
- 처음 기록하면 알이 깨지면서 마을 빈자리로 이사 가요. 📍 자리 옮기기로 마을 안 위치를 바꿀 수 있어요.
- 부화한 친구는 기본 4명처럼 레벨, 성장 현황 카드, 시간표, 달력, 말풍선이 다 붙어요.

## 📋 주간 정산 · 📔 일기 정리
- 결산 버튼의 "이번 주 정산"에 이런 게 모여요:
  - 한 주 총 시간(지난주와 비교), 기록한 날, MVP
  - 스킬별 목표 진행, 시간표 완료율
  - 릴스 업로드·팔로워 변화, 찬양 콘티, 개인 일정
- 블로그 일기를 붙여넣으면 AI 없이 정리해줘요. 날짜별 한 줄, 자주 쓴 말, 마음 날씨, 감사했던 순간, 일기에 많이 나온 스킬을 보여줘요.
- 일기는 이 아이패드에만 저장되고 GitHub에는 올라가지 않아요.

## 📚 북북이 스튜디오 (독서)
- 북북이를 누르면 옆 창에 열려요.
- 책 제목, 저자, ISBN으로 책을 찾아요. 기본은 구글 도서 검색이고 키가 필요 없어요. 카카오 REST API 키를 넣으면 카카오(다음) 책 검색으로 한국 책을 더 잘 찾아요. (알라딘 OpenAPI는 2026-11-01에 종료됐어요) 고른 다음 읽은 시간, 쪽수, 한 줄 메모를 남겨요. 시간을 적으면 독서 성장 기록에도 들어가요.
- 표지는 교보문고 이미지를 먼저 쓰고, 없으면 알라딘 표지를 써요. 책마다 "교보문고에서 보기" 링크가 있어요.
- 내 책장: 읽는 중 / 다 읽음 / 읽고 싶은 책. 달력과 주간 정산에도 나와요.
- 카카오 키는 이 아이패드에만 저장돼요. 코드나 GitHub에는 없어요.

## 🐱 모찌 채널 (일본어)
- 모찌를 누르면 옆 창에 '영적세계전문가' 유튜브 커뮤니티 게시물이 일본어로 떠요.
- 日本語 / ひらがな / 한국어 버튼은 하나씩도, 여러 개를 동시에도 켤 수 있어요. 일본어와 히라가나를 같이 켜면 한자 위에 읽는 법이 붙어요.
- GitHub Actions(`.github/workflows/mochi-posts.yml`)가 3시간마다 새 글을 찾아 번역하고, 히라가나를 붙여서 `mochi/posts.json`에 저장해요. 번역은 구글 번역을 쓰고, 막히면 MyMemory를 써요.
- 새 글이 올라오면 모찌가 말풍선으로 알려줘요. "다 읽었어요"를 누르면 일본어 공부 시간을 기록할 수 있어요.

### 모찌 일본어 공부 기능
- **낱말 뜻:** 글에서 낱말을 누르면 읽기, 뜻(네이버 일본어사전), JLPT 급수가 나와요. ⭐를 누르면 예문과 함께 단어장에 들어가요.
- **복습:** 단어장 낱말을 간격 반복으로 복습해요. 알았어 → 1·3·7·14·30·60·120일 뒤, 헷갈려 → 간격 절반, 몰랐어 → 처음부터.
- **후리가나:** 일본어와 ひらがな를 같이 켜면 기본은 N3보다 어려운 한자에만 붙어요. 모든 한자로 바꿀 수 있어요.
- **읽어주기:** 🔊 읽어주기와 🎧 쉐도잉(한 문장씩 읽고 따라 말할 시간)을 써요. 아이패드에 들어 있는 일본어 음성이라 비용이 없어요.
- **말풍선:** 모찌 말풍선 퀴즈(정답 보기 → 복습하기)와 🌸 오늘의 한 문장이 나와요.
- **기록:** 오늘 공부량(낱말·복습 정답률·쉐도잉·읽은 문장)을 보여주고, 쉐도잉·복습 시간은 "⏱ n분 공부 기록" 버튼으로 기록해요. 주간 정산에도 나와요.
